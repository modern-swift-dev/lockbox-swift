# Start with the API you need.

The guides explain Lockbox-specific behavior. The DocC reference documents the public Lockbox symbols available in a macOS package build. The examples also cover the iOS-only biometric service.

## [Getting started](/docs/lockbox-swift/documentation/getting-started/)

Install the package, save a password, read it, update it, and remove it.

## [Lockbox API reference](/docs/lockbox-swift/documentation/lockbox/documentation/lockbox/)

Browse generated DocC documentation for the public Lockbox module.

## [Generic passwords](/docs/lockbox-swift/examples/#generic-password)

Use a service and account to store a string or raw data.

## [Internet passwords](/docs/lockbox-swift/examples/#internet-password)

Save credentials that belong to a URL, protocol, and authentication type.

## [Keychain criteria](/docs/lockbox-swift/examples/#keychain-criteria)

Build lower-level queries when the password factories do not express your operation.

## [Local authentication](/docs/lockbox-swift/examples/#biometrics)

Evaluate a policy and protect iOS credentials with biometrics.
